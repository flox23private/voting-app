How it works

Up and running in under a minute

No accounts, no downloads, no setup. Just open a browser.

1

Host creates the quiz

Go to /admin, write your questions and answer options, mark the correct answer, and click Create Quiz.

2

Share the link

You instantly get a player link. Share it in your presentation, in chat, or via QR code. Players join on any device — phone, tablet, laptop.

3

Play live together

Hit Start Quiz. Everyone sees the question simultaneously. An 18-second timer counts down. Results appear automatically — you advance to the next question when ready.

Who does what

Two roles, one shared experience

One person hosts and controls the quiz. Everyone else joins as a player.

🎤

Host

You — the presenter or facilitator

  • Write 1–3 questions, each with 3 answer options
  • Mark the correct answer for each question
  • Share the generated player link with the room
  • Click Start Quiz when everyone is ready
  • Watch live vote totals come in as players answer
  • Click Next Question to advance after each reveal
🙋

Player

Everyone in the room

  • Open the shared link on any device
  • Wait on the lobby screen until the host starts
  • Read the question and tap your answer
  • Change your mind any time before the timer ends
  • See which answer was correct and how everyone voted
  • Your own choice is highlighted so you know how you did

FAQ

Common questions

Do players need to create an account?

No. Players just open the link in any browser — phone, tablet, or laptop. Nothing to install or sign up for.

How many players can join?

There is no hard player limit built into the app. In practice it handles group sessions comfortably — the server tracks each player by their anonymous connection.

Can I reuse a quiz?

Each quiz is created fresh per session. Once the session ends and the server restarts, the data is cleared. For now, just recreate the quiz — it only takes about 30 seconds.

What if a player joins late?

No problem. If a question is already running when they join, the app catches them up immediately and they can still vote. If the reveal has already happened, they see the results screen.

How long does each question last?

Exactly 18 seconds, enforced server-side. After that, the correct answer is revealed automatically and voting closes.

Does it work without an internet connection?

All devices need to reach the app server, which is hosted online. A stable Wi-Fi connection in the room is sufficient — mobile data also works.
